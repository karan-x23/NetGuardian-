# Contributing

Thanks for your interest in contributing to this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes with clear, focused commits.
4. Run the test suite before submitting a pull request.
5. Open a pull request with a short summary of the change.

## Code style

- Keep functions small and readable.
- Prefer clear variable names.
- Add tests for behavior changes.
- Avoid large unrelated refactors.

## Security note

This project is intended for ethical, local network monitoring on networks where you have permission to inspect traffic.
